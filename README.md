# Interactive Time Zone Converter

A responsive single-page time zone converter for online workshops.

## Features

- Convert between your local time and a destination time zone.
- Enter the other side's announced time and convert it back to Taiwan time.
- Recognize common abbreviations such as PDT, PST, EDT, EST, UTC, JST, and SGT.
- Create a prefilled Google Calendar event with video link and notes.
- Download an `.ics` calendar file with a reminder alarm.

## GitHub Pages

This site is static. GitHub Pages can serve it directly from the repository root:

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to Pages.
4. Select `Deploy from a branch`.
5. Choose the `main` branch and `/ (root)`.
